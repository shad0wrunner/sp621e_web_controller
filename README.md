# SP621e JS-based BT-enabled controller web-page
Web control for sp621e LED lamp controller. Replacement for shitty BanlanX/SceneX app.

Original sp621e controller for LED lamp from BanlanX/SceneX was crappy, so here is a simple JS-based BT-enabled web page to control your home lamp without signin' in and stuff. Just self-host, open it, enable BT through a browser, choose your device and use as you please
